Política de Privacidad

Última actualización: Septiembre 2026

FuelPrice ("nosotros", "la aplicación") se compromete a proteger la privacidad de sus usuarios. Esta política describe cómo se gestionan los datos cuando utiliza la aplicación FuelPrice.

1. Datos de ubicación

FuelPrice puede solicitar acceso a la ubicación del dispositivo para mostrar las gasolineras más cercanas al usuario y facilitar la búsqueda de estaciones de servicio próximas.

La ubicación se utiliza para proporcionar esta funcionalidad y no almacenamos ni compartimos directamente su ubicación personal en servidores propios.

2. Información sobre precios de combustible

FuelPrice utiliza información pública sobre precios y estaciones de servicio proporcionada por fuentes oficiales, incluyendo datos del Ministerio para la Transición Ecológica y el Reto Demográfico (MITECO).

Estos datos se utilizan exclusivamente para mostrar información sobre las estaciones de servicio y sus precios de combustible dentro de la aplicación.

3. Servicios de terceros (Anuncios y Analítica)

Para mantener la aplicación gratuita y mejorar su funcionamiento, utilizamos servicios de terceros:

  • Google AdMob: FuelPrice utiliza Google AdMob para mostrar anuncios. AdMob puede recopilar identificadores de publicidad, información del dispositivo y otros datos necesarios para proporcionar, medir y personalizar los anuncios, de acuerdo con las preferencias de privacidad del usuario y la normativa aplicable.
  • Google Analytics para Firebase: Podemos utilizar Firebase Analytics para recopilar información estadística sobre el uso de la aplicación, como eventos, modelo de dispositivo, sistema operativo y otra información técnica, con el objetivo de comprender el uso de la aplicación y mejorar su funcionamiento.

4. Consentimiento y usuarios de la Unión Europea

Para los usuarios del Espacio Económico Europeo (EEE), Reino Unido y Suiza, FuelPrice utiliza el sistema de gestión del consentimiento de Google para solicitar y gestionar las preferencias relacionadas con el uso de datos personales para publicidad y otros fines.

Los usuarios pueden aceptar, rechazar o gestionar sus preferencias de consentimiento cuando se les muestre el mensaje correspondiente. También pueden modificar sus preferencias posteriormente desde las opciones de privacidad disponibles en la aplicación, cuando esta función esté disponible.

5. Almacenamiento local

FuelPrice puede almacenar determinados datos de configuración y preferencias de la aplicación de forma local en el dispositivo. Estos datos se utilizan para que la aplicación pueda funcionar correctamente y recordar las preferencias del usuario.

6. Seguridad y terceros

FuelPrice no vende los datos personales de sus usuarios. Los servicios de terceros utilizados por la aplicación pueden procesar determinados datos de acuerdo con sus propias políticas de privacidad y las finalidades para las que han sido integrados.

7. Derechos de los usuarios

Si reside en el Espacio Económico Europeo (EEE), Reino Unido o Suiza, tiene determinados derechos en relación con sus datos personales, incluyendo el derecho de acceso, rectificación, supresión, oposición y limitación del tratamiento, cuando sean aplicables.

Las solicitudes relacionadas con el tratamiento de datos realizado directamente por servicios de terceros deberán dirigirse también al proveedor correspondiente, como Google, cuando proceda.
